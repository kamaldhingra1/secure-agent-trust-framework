# Contributing

SATF is intended to be a living framework. Contributions should improve clarity, implementation guidance, control mappings, maturity criteria, examples, diagrams, or evidence artifacts.

## Contribution types

- Concept improvements
- Control catalog additions
- Maturity model improvements
- Example scenarios
- Alignment mappings
- Diagrams
- Templates and checklists

## Review principles

Contributions should keep SATF:

- Vendor-neutral
- Security-practitioner friendly
- Clear about conceptual vs operational planes
- Grounded in measurable controls and evidence
- Suitable for enterprise, regulated, and high-risk environments
