# Coding Agent Pattern

## Purpose

Describe the agent pattern and expected autonomy level.

## Common Risks

- Goal overreach
- Unsafe tool use
- Data exposure
- Delegation risk
- Memory contamination

## Required SATF Capabilities

- Agent Trust Fabric
- Trust Establishment
- Trust Enforcement
- Trust Validation
- Governance, Telemetry, and Assurance
- Runtime and Response Plane

## Recommended Controls

- Define human controller
- Establish least agency
- Add contextual PDP/PEP
- Instrument telemetry
- Validate goal integrity
- Apply step-up review for high-risk actions

## Evidence Artifacts

- Agent inventory record
- Control mapping
- Policy decision logs
- Tool invocation logs
- Assurance results
