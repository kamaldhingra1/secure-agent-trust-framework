# TrustOps Metrics

TrustOps requires measurable indicators of Mission Trust.

## Suggested metrics

| Metric | Purpose |
|---|---|
| Mission Trust Index | Composite confidence score for an autonomous mission |
| Trust Decision Latency | Time required to make a trust decision after new evidence appears |
| Trust Recovery Time | Time required to re-establish justified trust after degradation |
| Evidence Freshness | Age and validity of evidence used for trust decisions |
| Delegation Integrity Score | Degree to which delegation remains scoped, traceable, time-bound, and valid |
| Secure Outcome Success Rate | Percentage of missions producing safe, trusted, compliant, resilient, and expected outcomes |
| Trust Decay Rate | Frequency or velocity of confidence degradation |
| Human Intervention Rate | Frequency of step-up review or human intervention |
| Policy Exception Rate | Frequency of exceptions required to continue mission execution |
| Re-establishment Success Rate | Percentage of trust recovery attempts that successfully restore mission trust |

## Metric design principle

TrustOps metrics should measure enterprise confidence, not merely technical performance.
