# Trust Decision Records

## Purpose

Trust Decision Records capture the rationale, evidence, policy context, and outcome of key trust decisions during an autonomous mission.

They are intended to support auditability, assurance, post-mission review, and continuous improvement.

## Suggested fields

```text
Decision ID
Mission ID
Agent ID / Agent Chain
Decision Time
Decision Type
Trust State Before Decision
Evidence Considered
Policy Applied
Decision Outcome
Action Taken
Human Approval Required
Trust State After Decision
Recovery / Re-establishment Requirement
Reviewer / Owner
Lessons Learned
```

## Example decision outcomes

```text
Allow
Constrain
Step-Up Review
Monitor
Pause
Contain
Revoke
Re-establish
Terminate Mission
```

## Relationship to SATF

Trust Decision Records provide evidence for:

- Trust decay analysis
- Delegation provenance review
- Goal integrity review
- Adaptive policy improvement
- Secure outcome reporting
