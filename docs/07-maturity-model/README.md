# Maturity Model

| Ring / Plane | L1 Ad hoc | L2 Defined | L3 Managed | L4-L5 Optimized |
|---|---|---|---|---|
| Establishment | Shared credentials, no owner map | Unique identity, named owners | Least agency by default | Continuous credential rotation and lifecycle automation |
| Enforcement | Static allowlists | Contextual policy for high-risk actions | PDP/PEP for meaningful actions | Real-time policy tuned by live trust score |
| Validation | No adversarial testing | Periodic red-team exercises | Continuous monitoring and Rule of Two | Automated containment on drift or assurance failure |
| Governance / Telemetry / Assurance | No agent inventory | Inventory and risk tiers | Audit trail for all agents | Evidence feeds reporting and policy adaptation directly |
| Operational plane | Manual response | Documented playbooks | SOAR-integrated response | Automated containment with human-governed recovery |
