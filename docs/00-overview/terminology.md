# Terminology

## Agent Trust Fabric

The dynamic evaluation engine that combines identity, intent, context, goal, dynamic risk, behavior, and delegation provenance.

## Trust Establishment

Controls that create a secure starting posture before agent execution.

## Trust Enforcement

Runtime authorization and policy enforcement for agent actions.

## Trust Validation

Controls that prove whether trust assumptions still hold under drift, manipulation, and adversarial conditions.

## Cross-Cutting Control Plane

Governance, telemetry, and assurance capabilities that observe and adapt the trust model continuously.

## Runtime and Response Plane

The operational surface where agents run, actions are contained, and outcomes are produced.
