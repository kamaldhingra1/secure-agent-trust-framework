# Why SATF Is Needed

Enterprise security models were built around human users, applications, workloads, and APIs. Agentic AI changes the trust problem because agents can interpret open-ended goals, select tools, maintain context, act across systems, and coordinate with other agents.

A static permission grant is not enough when an agent can transform a benign request into a multi-step action chain.

SATF is designed to answer one question:

> When should an enterprise trust an agent to act autonomously, and how should that trust be continuously constrained, observed, validated, adapted, and revoked?

## Why existing models are insufficient

Traditional identity and access management answers:

- Who are you?
- Are you authenticated?
- Do you have permission?

Agent trust requires additional questions:

- What goal is the agent pursuing?
- Who delegated the work?
- What context is the agent operating in?
- What tools, data, and memory are being used?
- Has the agent drifted from the approved objective?
- Does the current behavior match expected behavior?
- Should trust decay, trigger step-up review, or invoke containment?
