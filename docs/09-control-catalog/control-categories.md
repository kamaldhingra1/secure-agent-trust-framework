# SATF Control Categories

SATF controls are organized around framework areas and outcome roles.

## Category A: Agent Trust Fabric Controls

Controls that evaluate the trust state of an agent, mission, action, context, goal, behavior, risk, and delegation chain.

Example controls:

- Agent Identity
- Goal Integrity
- Delegation Provenance
- Agent Risk Evaluation
- Trust Scoring

## Category B: Ring 1 - Trust Establishment Controls

Controls that establish the initial trust posture before autonomous execution.

Example controls:

- Human Accountability
- Agent Registration
- Agent Authentication
- Least Agency
- Memory Integrity
- Supply Chain Integrity

## Category C: Ring 2 - Trust Enforcement Controls

Controls that determine whether a specific agent action should occur under current context.

Example controls:

- Contextual Authorization
- Tool Access Control
- Data Access Control
- Objective Boundary Enforcement
- Approval Gates
- Fail-Closed Enforcement

## Category D: Ring 3 - Trust Validation Controls

Controls that continuously validate whether trust assumptions remain true.

Example controls:

- Goal Validation
- Agent UEBA
- Reward-Hacking Detection
- Rule of Two Validation
- Adversarial Testing
- Evidence Validation

## Category E: Control Plane Controls

Controls that govern, adapt, assure, and improve trust policy based on telemetry, validation, and evidence.

Example controls:

- Trust Telemetry
- Trust Policy Governance
- Exception Management
- Trust Assurance
- Trust Intelligence

## Category F: Runtime and Response Plane Controls

Controls that contain, recover, and re-establish trust after trust degradation or failure.

Example controls:

- Trust Containment
- Trust Recovery
- Trust Re-establishment
- Credential Revocation
- Mission Suspension
