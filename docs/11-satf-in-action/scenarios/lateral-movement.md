# What If an Agent Begins Lateral Movement?

## Problem

An agent attempts to move across systems, clusters, credentials, or environments beyond intended scope.

## SATF Coverage

### Ring 1: Trust Establishment

- Segmentation
- Least agency
- Credential scoping

### Ring 2: Trust Enforcement

- Network policy enforcement
- Delegation controls
- Contextual authorization

### Ring 3: Trust Validation

- UEBA
- Behavioral monitoring
- Threat validation

### Control Plane

- Trust score decay
- Adaptive policy tightening

### Runtime and Response Plane

- Isolation
- Shutdown
- Recovery
