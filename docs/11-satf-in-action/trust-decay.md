# What If Trust Decays?

## Problem

An agent's trust state degrades due to new evidence.

Common triggers:

- goal drift
- excessive delegation
- unsafe tool usage
- memory poisoning
- behavioral anomalies
- policy violations
- assurance failures
- supply chain concerns

## SATF Response

```text
Allow -> Constrain -> Step-Up Review -> Monitor -> Contain -> Revoke -> Re-establish
```

## Re-Establishment

Trust can be re-established through:

- revalidation
- remediation
- credential rotation
- policy update
- human approval
- assurance testing

## SATF Principle

```text
Trust is not granted once.
Trust decays, adapts, and must be continuously enforced.
```
