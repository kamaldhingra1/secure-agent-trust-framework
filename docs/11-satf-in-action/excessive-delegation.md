# What If an Agent Delegates Too Much Authority?

## Problem

Delegation chains expand authority beyond approved scope.

```text
Human -> Agent A -> Agent B -> Agent C -> External Action
```

## SATF Coverage

### Agent Trust Fabric

- Delegation provenance
- Delegation lineage

### Ring 2: Trust Enforcement

- Scope attenuation
- Delegation TTL
- Approval thresholds
- Step-up review

### Ring 3: Trust Validation

- Delegation anomaly detection
- Delegation chain validation

## SATF Principle

```text
Delegated Trust Is Not Inherited Trust
```
